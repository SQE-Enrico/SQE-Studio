# SQE Studio / 0.1.1.dev81

SQE Studio connects declarative Quantum Metal layouts, native electromagnetic
jobs and source-bound quantum studies through a local browser application.
Open **Launch SQE Studio.pyw** with the existing scientific environment.

The **Native single transmon** starter provides one isolated two-pad
TransmonPocket. Review the process and ground assumptions, save the revision
and run its capacitance study. In Results, select the verified source, declare
additional junction capacitance and E_J/h or L_J, preview the reduction and
run the conditional scqubits study. See the full
[single-transmon workflow](docs/SINGLE_TRANSMON.md) for assumptions and evidence.

From the enclosing Git workspace:

```powershell
.\dev.ps1
.\dev.ps1 -Watch
.\dev.ps1 -Profile software
.\dev.ps1 -Profile single_transmon
```

Recommended covers source integrity, focused regressions and authenticated HTTP.
Software adds all portable domains, real Chromium and an isolated wheel install.
Single transmon runs the official Palace reference, real saved native jobs,
browser actions and source-rejection checks. Missing native tools remain BLOCKED.
Numbered reports and the machine-readable summary are in qualification-reports/.

[CURRENT_STATE.json](CURRENT_STATE.json), then use `python tools/context.py`.
