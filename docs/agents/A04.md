# A04 — scqubits adapter execution and input contract

Scope: `src/sqe_studio/adapters/scqubits_adapter.py` and A04-owned tests/reports only. This is an agent delta, not an integrated product release or an EM quantization implementation.

## Independent Hamiltonian studies

A study remains the frozen core shape `{"id": ..., "engine": "scqubits", "kind": "spectrum", "inputs": {...}}`. The `inputs` field is declarative JSON only. A minimal, *explicitly entered* standalone transmon is:

```json
{
  "source": "independent", "model": "Transmon", "levels": 3,
  "parameters": {"EJ": 15.0, "EC": 0.25, "ng": 0.0, "ncut": 12, "truncated_dim": 6},
  "parameter_units": {"EJ": "GHz", "EC": "GHz", "ng": "2e", "ncut": "1", "truncated_dim": "1"},
  "convergence": {"enabled": true, "tolerance_GHz": 0.01, "basis_increment": 4}
}
```

Native parameters are **frequencies `E/h` in GHz**, flux in `Phi0` (normalized to 0..1), offset charge `ng` in Cooper-pair units `2e`; dimensionless basis sizes and SQUID asymmetry `d` use `1`. The adapter does not convert Joules, capacitance, impedance, CAD distances or cavity/eigenmode frequencies to qubit `EJ`, `EC`, `EL` or `g`. The legacy foundation study lacking `source` and `parameter_units` remains accepted as independent GHz input, with `parameter_units_explicit: false` recorded in the result. Do not use that legacy form for an EM-extracted model. `truncated_dim` absent on a standalone study is deterministically resolved to `max(6, levels)` and included under `resolved_basis`; it is required explicitly for composites.

Supported native devices: `Transmon` (`EJ`, `EC`, `ng`, `ncut`), `Fluxonium` (`EJ`, `EC`, `EL`, `flux`, `cutoff`), `TunableTransmon` (`EJmax`, `EC`, `d`, `flux`, `ng`, `ncut`), with optional `truncated_dim`. No raw Hamiltonian expression or arbitrary class/module loading is accepted. `levels` is 2..12, native basis `ncut`/`cutoff` is 3..80, `truncated_dim` is 2..16, and all energies are positive and at most 1000 GHz. Inputs must be finite JSON numbers; booleans cannot substitute for numbers.

## Composite coupling

The allowlisted `Composite` model uses 2..3 named `Transmon`, `Fluxonium`, or `TunableTransmon` subsystems; every subsystem requires its own `parameters`, complete `parameter_units`, and `truncated_dim`. The product of truncated dimensions must be <=144. Each of 1..3 interactions is a fixed, Hermitian charge-charge operator product; a sample interaction is:

```json
{"left": "q1", "right": "q2", "operator_left": "n_operator", "operator_right": "n_operator", "g": 0.025, "unit": "GHz"}
```

The native scqubits `HilbertSpace` is constructed with allowlisted bound `n_operator` methods and `add_interaction(g=..., op1=..., op2=...)`. The adapter requests native eigenvalues for the coupled system and for an otherwise identical native unlinked Hilbert space. `coupling.json` reports both absolute energy tables and their level-wise differences. It does **not** estimate physical coupling from EM, perform a fit, or claim that an energy shift is measured `g`.

## Bounded sweeps and convergence

A sweep is `{"subsystem":"primary", "parameter":"flux", "values":[0.4,0.5,0.6], "unit":"Phi0"}` for a standalone Fluxonium (for a composite use the named subsystem id). Supports selected continuous native parameters, up to 21 explicit saved values. No arbitrary sweep formulas or cutoffs in sweeps. Each point invokes the native engine; outputs include axes and plotted series metadata (absolute eigenenergies and transitions from ground). Native spectral results are always `review_required`.

Optional convergence requires `{"enabled":true,"tolerance_GHz":0.01,"basis_increment":4}`. At **every point** the adapter recalculates native eigenenergies with enlarged cutoff (and truncated subsystem dimension when specified), comparing ground-referenced transitions in GHz. If the maximum discrepancy exceeds the requested tolerance, the run fails closed with the point index and measured discrepancy; no success manifest is issued. A passing *single basis step* is not a scientific convergence proof for all observables, nor a full basis/mesh convergence study. The enlarged composite Hilbert product must also remain <=144.

## Provenance and stale bindings

`input_sha256` may be supplied as SHA-256 of the canonical `inputs` JSON **excluding `input_sha256` itself**; `context_sha256` may be supplied as SHA-256 of `{"schematic":project.schematic,"layout":project.layout,"process":project.process}`. JSON canonicalization: `json.dumps(x, sort_keys=True, ensure_ascii=True, separators=(',', ':'), allow_nan=False).encode('utf-8')`. Mismatch blocks before engine import. If not provided, these stamps do not provide an anti-staleness guarantee; immutable revision identity/security is enforced upstream by the frozen Jobs/worker flow. The `input_snapshot.json` records canonical study/project/input hashes, both optional stamps, resolved basis, unit convention and installed engine/dependency versions.

**EM-derived/engine-derived input is blocked in this ABI**, even when a caller includes strings such as `verified_em: true`. Only a trusted A01 lineage certificate tied to the *actual immutable job revision and source artifact hashes*, with verified dimensions, units and quantization method, can justify a later derived-model path. User-controlled JSON metadata is not such a certificate. See `reports/agents/A04/REPORT.md` for the required A09 contract migration.

## Artifact contract for A06/A07

- `input_snapshot.json`: `sqe.scqubits.input-snapshot.v1`, canonical hashes, resolved basis and versions.
- `spectrum.json`: `sqe.scqubits.spectrum.v1`, typed `scqubits.spectrum`, native energy table, axis, basis, convergence per point aggregate and nonqualified status. `levels`/`units` preserve foundation UI's first-point preview; `preview_point_index: 0` identifies it. For sweeps, the current UI only previews the first point pending A07 work.
- `series.json`: `sqe.scqubits.series.v1`, `E0`, `E1`, ... and `f01`, `f02`, ... series, explicit x axes and GHz units (for A07 plotting and A06 iteration).
- `coupling.json` for composites: `sqe.scqubits.coupling.v1`, explicitly entered interaction strengths and native linked-vs-unlinked energy levels (not fitted/experimental coupling).

The frozen worker hashes files and writes a revision-bound `sqe.artifact.v1` manifest. Additional typed subartifact names require A09 contract review; A04 does not alter the frozen registry, manifest schema or artifact taxonomy. The native runtime dependency remains `scqubits>=4.3,<5` (with its own installed dependencies, including QuTiP); this delta adds no install scripts or dependencies.
