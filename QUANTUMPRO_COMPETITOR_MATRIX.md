# QuantumPro competitive capability matrix

Checked against official public sources on 2026-11-05. This is an engineering
gap assessment, not a claim of product equivalence. The live working tree is
the implementation baseline. Evidence and unresolved tests are recorded in
[LOCAL_FULL_TEST_REPORT.md](LOCAL_FULL_TEST_REPORT.md).

The primary reference is **W3704B**: integrated layout, FEM eigenmode/frequency
analysis, Momentum frequency analysis, quantum extraction, linear circuit
co-simulation, Python automation and kinetic-inductance modeling. [K1]
**W3715B** adds harmonic balance. [K2] **W3706B** includes harmonic balance,
envelope and transient/convolution simulation and an extended device library.
Those extended nonlinear capabilities are tracked separately. [K3]

Confidence terms: **native validated** means a real execution compared with an
independent reference for that stated case; **native conditional** means real
execution with incomplete physical accuracy/generalization evidence.
**Fixture-tested**, **untested**, **unsupported** and **blocked** are distinct.
Passing software tests never upgrades scientific confidence automatically.
