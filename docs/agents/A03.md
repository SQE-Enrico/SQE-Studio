# A03 native electromagnetic adapter contract

**Status: code and fail-closed tests delivered; native run blocked in the delivery environment.**
This module implements a restricted SQDMetal/Gmsh/Palace bridge without any
replacement FEM solver, synthetic S-parameters, or assumed native results.
The frozen ABI is `run(study, project, output_dir)`. The A06 worker supplies the
revision-bound snapshot and hashes the returned files. A03 does not impersonate
A01's versioned interoperable artifact schema.

## Required physical inputs

A saved `project` must contain `layout.engine=quantum_metal`, a real A02
QDesign recipe in `layout.components`, a chip with `thickness_um`,
`process.source=reviewed`, and a complete **three-region** stack in this order:

```json
[
 {"role":"substrate","material":"silicon","thickness_um":500,
  "relative_permittivity":11.7,"loss_tangent":0},
 {"role":"metal","material":"aluminium","layer":1,
  "thickness_nm":100,"em_model":"PEC"},
 {"role":"superstrate","material":"vacuum","height_um":500,
  "relative_permittivity":1.0,"loss_tangent":0}
]
```

These values are only **illustrative user inputs**, not validated process
values or material assertions. Only a single uniform silicon/sapphire
substrate, uniform PEC aluminium metal layer and vacuum cap are supported.
The adapter checks that the SQDMetal-generated deck has exactly the declared
air/substrate material constants and physical groups. A true multilayer,
kinetic-inductance, anisotropic or finite-conductivity stack is **blocked**.
No missing material or physical boundary gets an auto-selected default.

The study uses `kind=capacitance|eigenmode|sparameters`,
`engine=sqdmetal_palace`, and **only** `inputs.em`:

```json
{
 "ground":{"kind":"qdesign_ground_plane","layer":1,"verified":true},
 "boundaries":{"x_neg_um":200,"x_pos_um":200,"y_neg_um":200,
               "y_pos_um":200,"z_neg_um":0,"z_pos_um":500,"farfield":"pec"},
 "ports":[{"index":1,"kind":"junction","component":"Q1",
           "L_nH":10,"C_fF":1}],
 "mesh":{"min_um":10,"max_um":100,"refinement_levels":[0,1,2],
         "relative_tolerance":0.02},
 "execution":"deck_only",
 "solver":{"order":2,"tolerance":1e-8,"max_iterations":100,
           "num_cpus":2,"start_hz":5000000000,"modes":2}
}
```

This is an **illustrative eigenmode request** and is not a tested scientific
input. `capacitance` instead requires `farfield=ground`, conductor ports with
explicit ordered `native_attributes` (Gmsh physical IDs), and a solver with
only the common fields. No capacitance terminal correspondence is inferred.
RF/eigenmode ports can be `cpw_launcher` (component, length_um,
impedance_ohm), `cpw_route` (plus start/end pin), or eigenmode-only
`junction` (L_nH, C_fF). All ports are contiguous one-based indices in
SQDMetal creation order. `sparameters` requires an explicit `excited_port`
and a strictly uniform `frequencies_hz` grid of 2–201 points. Only the
excited column from native `port-S.csv` is represented; no full S-matrix is
invented. The A02 QDesign must actually contain the referenced geometry.

## Native execution gate and files

`run` always validates the complete stack, ground, boundaries, ports,
units, solver budget and mesh convergence **plan** before importing native
engines or creating a folder. It requires an A02-owned public
`quantum_metal_adapter.build_qdesign(project)` function. The untouched
foundation does not export one, so the adapter **blocks** rather than
reconstructing or guessing Quantum Metal components. A02/A09 must review
this interface before a combined native trial.

When the above contract is supplied, installed native SQDMetal constructs a
3D metal-thickness model, defines ground/physical ports, generates the Gmsh
volume mesh and writes its own Palace JSON. A03 verifies nonempty 3D
Gmsh elements, physical-region tags, deck material properties, boundary tags,
numbered ports, frequency sweep and a constrained relative output directory.
There is **no** SQE-produced mesh or solver deck. `deck_only` does not need
a Palace binary, but is still a real SQDMetal/Gmsh operation when possible.

`solve` additionally requires a verified operator-configured Palace executable.
On Linux or native Windows, set `SQE_PALACE_BACKEND=native` and the absolute
executable path in `SQE_PALACE_BINARY`. For Windows 11 + WSL, set
`SQE_PALACE_BACKEND=wsl` and the Linux absolute executable path in
`SQE_PALACE_WSL_BINARY`; `wsl.exe` and mounted output path must be available.
No path, shell string or arbitrary import name comes from project data.
Palace is invoked with an argv list, bounded to 120 seconds; native return
code and required raw CSV must pass. A `--version` probe must identify Palace
or execution blocks. SQDMetal's own shell-script `run` helper is not called.

Successful run outputs, **when native engines are actually available**, are
`a03-native-artifacts.json` (type, content hashes, versions, Hz axis, port map,
units, planned but unverified convergence), `sqe_em/sqe_em.msh`,
`sqe_em/sqe_em.json`, and, for `solve`, `sqe_em/palace-native.log` and one
native result under `sqe_em/outputFiles/` (`eig.csv`, `terminal-C.csv` or
`port-S.csv`). Native output is not qualification. A06 worker's
`RESULT_MANIFEST.json` binds these files to the saved revision.

## Review before admission to scientifically enabled deployments

- A02 must publish a deterministic and tested `build_qdesign(project)` with
  actual component/pin/ground geometry and stable layer identities.
- A01/A09 must version and review the `inputs.em` material/port schema,
  terminal/ground evidence and artifact types; the frozen schema presently
  allows opaque study inputs, and the frozen adapter ABI carries no revision ID.
- A03 must undergo a real SQDMetal/Gmsh generated deck test, a Palace
  electrostatic/eigenmode/driven smoke, independent material/port mapping
  review, convergence comparison and Windows+WSL validation. None was
  performed in the delivery environment. This feature remains HOLD.
