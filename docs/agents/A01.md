# A01 — typed scientific interoperability and review gates

Schema/API family: `sqe.interop.a01.v1`. Scope: `src/sqe_studio/interop/` only. This is an **independent A01 candidate**, not a merged implementation and not a qualified scientific result. All paths in this document refer to A01-owned modules. No frozen ABI, registry, project schema, contracts, setup, solver or GDS writer was changed.

## Interface boundary

Import from `sqe_studio.interop` (Python 3.11+; stdlib only). All domain records are frozen dataclasses. Numerical fields are exact `Decimal`-backed `Quantity(value, unit, Dimension)`; enum dimensions cannot be exchanged even when the text unit matches. `schema_version='sqe.quantity.v1'` is checked. Portable values include explicit schema, dimension, unit and a **decimal string**; consumers MUST NOT silently replace it with binary float or interpret `GHz` as angular frequency. `Dimension.ENERGY_OVER_H` signifies a separately documented E/h quantity in cycle-frequency units; it is not the result of a built-in Hamiltonian derivation. Converting a `Dimension.FREQUENCY` into `Dimension.ENERGY_OVER_H` is prohibited. Unit rescaling is pure, exact and auditable (`frequency_as`, `capacitance_as`, `Quantity.as_unit`). Only enumerated SI prefix units are supported. Values must be finite.

Typed records include:

| Layer | Records and invariants |
| --- | --- |
| Source truth | `RevisionBinding` (project/revision UUID + revision SHA-256), `ArtifactRef` (type, hash, producing engine and version, frozen artifact schema), `EvidenceRecord` (review kind, reviewer id, review-document SHA-256, exact parent hashes), `ProvenanceEdge` (checked source/target revision + cited parents). |
| Electrical topology | `CircuitNetlist`, `CircuitElement`, `CircuitPort` with explicit positive/negative or signal/return nodes and contiguous **one-based** ports; no implicit ground. Junction parameter is explicitly E/h, not an invented geometric energy. |
| Geometry declaration | `Point2D`, `QGeometryPin` (two length-typed endpoints, nonzero width, named component/pin); `PortPinMapping` (distinct signal and return); `ElementGeometryMapping` (every netlist element mapped by geometry id, explicit polarity, kind, component id). These are reviewed recipe **declarations**, not observed native QGeometry. |
| EM and solver | `MeshRegion` (native Gmsh physical group + material role), `SolverPort` (1-based index, distinct signed boundary tags, circuit-port identity, positive real reference impedance), `EMMode`, `CapacitanceMatrix` (explicit Maxwell/mutual sign convention and native source). No material, boundary or capacitance values are computed. |
| RF networks | `NetworkNormalization` (S/Y/Z, per-port reference impedance + plane, explicit wave or V/I convention), `NetworkSample` (explicit frequency and complex square matrix), `NetworkObservation` (native/measured origin). `S` is dimensionless, `Y` Siemens and `Z` ohms. Native Y/Z representations remain blocked until a frozen artifact-type migration; `measurement.dataset` may declare Y/Z without claiming any native engine support. |
| Quantum parameters | `HamiltonianTerm` with allowed parameter identifier, dimensioned E/h value, approved **method label**, producing model and exact EM source hashes; this record never computes or verifies a derivation. |

### Pure handoff functions

**A02: `preflight_design_to_qdesign`** requires a saved typed `CircuitNetlist` source, a hashed `quantum_metal.qdesign_recipe`, explicit declared component IDs, complete declared QGeometry pins, a bijective circuit-port-to-signal/return-pin correspondence, and one `ElementGeometryMapping` for **every** netlist element. It verifies matching signed terminals and element kind. It then requires `netlist_review`, `geometry_review` and `port_correspondence` review documents bound to the relevant source hashes and same active revision. Missing, stale, duplicate or ambiguous mappings raise `MissingEvidence`, `StaleRevision` or `UnsafeMapping`. It returns only `QDesignHandoff(status='PREFLIGHT_ONLY_NOT_NATIVE_EXECUTION')`. It does not construct a QDesign, assign GDS layers or claim those pins physically exist. The A02 native adapter must verify that its generated geometry matches the declarations; a plain handoff is never a fabrication signoff.

**A04: `preflight_em_to_quantum`** accepts typed native Palace modes and optional native capacitance, explicit `HamiltonianTerm` records and four independent kinds of review: mode identification, quantization derivation, coupling review and extraction validation. Every source artifact must be associated with a supplied term, each reviewed term must cite only sources from the same active revision, and all three per-term derivation/coupling/validation reviews must cover its parent hashes. The returned `QuantumModelHandoff` is **not** a calculated Hamiltonian or proof of reviewer identity. Raw mode frequencies and C-matrix values never become EJ/EC/EL/g implicitly. No use of scqubits or any other solver is triggered.

**A06: `reviewed_edge`** creates a strict provenance edge across immutable, same-revision references with evidence coverage of all parents. This is a metadata check; the host job/store MUST read/verify actual artifact bytes, review-document bytes and author authorization before persisting or executing an edge. `content_digest` and `canonical_json` are deterministic for typed records but **do not** authenticate an attacker-supplied `ArtifactRef`.

**Pure re-encoding:** `convert_network_frequency_units` converts only frequency prefixes; `reorder_network_ports` requires an explicit complete permutation, transposes neither physical convention nor impedance, and permutes matrix rows, columns, boundary metadata and reference planes together. Original **circuit_port** identity is preserved while new solver port indices become 1..N. These functions preserve a source reference; they do not create a new native solver artifact. No S/Y/Z conversion, reference impedance renormalization, EPR, black-box quantization, solver, mesh, GDS or geometry writer is implemented.

## Mapping decision records

| ID | Decision | Why / fail-closed behavior |
| --- | --- | --- |
| A01-M01 | Treat `E/h` and ordinary frequency as distinct dimensions even when in GHz. | GHz-vs-Hz rescaling is valid; equating an EM eigenfrequency and EJ/EC is *not* an allowed unit conversion. |
| A01-M02 | Treat terminal and port polarity as explicit identifiers, not netlist parsing or implied chassis ground. | Refuse missing return, zero-based numbering, missing port/pin/element mappings, duplicate IDs or unmatched geometry. |
| A01-M03 | Require native artifact hashes, a single immutable revision, explicit review document IDs/hashes and full parent coverage. | Typed evidence is necessary but not sufficient: host must authenticate reviewers and independently check all bytes/hashes. |
| A01-M04 | Use signed Maxwell C (positive diagonal, nonpositive off-diagonal) vs nonnegative mutual C; require convention. | Prevent common sign inversion; no fabricated capacitance or inferred numerical symmetry/tolerance. |
| A01-M05 | Model S/Y/Z normalization with real positive port impedances, distinct planes and explicit wave vs V/I semantics. | No silent 50-ohm assumption, port renumbering or unsafe native S/Y/Z conversion. Native Y/Z output types are not in the frozen artifact registry. |
| A01-M06 | Geometry, mesh and quantum metadata are **declarations** only, never solver readiness. | A02–A06 must verify native runtime, native source outputs, material/boundary/port mapping and independent reviews before native actions. |
| A01-M07 | No arbitrary code snippets, shell strings, dynamic imports or free-form plugin entrypoints in model inputs. | IDs and enum values are bounded; source artifacts must come from allowlisted engine IDs or audited external data. |

## Agent handoffs (non-invasive declarations)

`DECLARATIONS` / `compatibility_for('A02' ... 'A06')` are static `CompatibilityDeclaration` records; they do **not** patch other agents' adapters. A02 consumes the QDesign handoff (once its native mapping is independently verified); A03 validates mesh regions, native outputs and solver ports; A04 consumes only reviewed Hamiltonian values; A05 validates signed Josephson netlist and Julia RF ports; A06 integrates revision/evidence edges and authenticates immutable data. Missing installed engines remain blocked in the respective native adapter. Consumers should use these contracts through explicit module imports, NOT arbitrary import paths.
