# A06 — revision-bound native orchestration

Owned implementation: `src/sqe_studio/orchestration/`, `src/sqe_studio/jobs.py`, `src/sqe_studio/worker.py`. SQE Studio performs neither numerical simulation nor GDS writing.

## Explicit artifact DAG

The topological stages declared in `ArtifactDAG` are:

```
immutable revision -> A02 Quantum Metal QDesign recipe
  +-> A02 native GDS (HOLD)
  +-> A03 Gmsh mesh -> A03 Palace deck -> native EM modes / capacitance / S-parameters
                                                  +-> A01 reviewed quantum parameter map -> A04 scqubits spectrum
immutable revision -> A01 verified circuit netlist -> A05 native Josephson S-parameters
```

Dependencies enforce exact artifact type, source revision/hash, manifest SHA-256 and parent-bound approval evidence. Nodes are **not executable in the baseline** until a trusted A01/A02/A03/A04/A05 integration explicitly declares a typed capability. The foundation does not produce a standalone QDesign recipe, reviewed quantization mapping, verified circuit netlist or Palace mesh/deck. No user-controlled input can turn on unavailable graph bridges. The existing direct saved-study path still invokes an allowlisted native adapter, or fails closed if it cannot operate.

## Interfaces and files

- `orchestration/dag.py` supplies DAG dependencies, topological ordering, `require_ready` and `next_ready`. Review decisions require a reviewer, valid evidence digest, exact revision/source and ordered parent manifest hashes.
- `orchestration/artifacts.py` validates real output files/manifest hashes, typed output/source identity, native engine and adapter version. `fingerprint` covers the revision ID, source digest, saved or swept study options, native-engine version, adapter-source digest and upstream manifest digests. A cache hit must rehash the native files before reuse.
- `orchestration/sweep.py` produces deterministic, immutable numeric changes to already-saved study inputs: one manually selected point or at most 24 automatic sequential points. Arbitrary code, arbitrary option paths, nonfinite values and multiple parallel jobs are rejected.
- `worker.py` validates source digest/saved study (including exact numeric sweep derivation), adapter source hash, engine-reported version and native file allowlist; it emits `RESULT_MANIFEST.json` only after a real installed adapter returns files. Missing/incomplete mappings leave `FAILURE.json` and a failing exit code. Every success remains `review_required` and fabrication `HOLD`.
- `Jobs.start(owner,pid,rev,study_id, *, parents=(), force=False)` preserves the foundation API. Existing direct results may be reused only if their native and adapter versions, options and all hashes match the current revision. Cross-engine parents are deliberately blocked until A01's typed review interface is integrated.
- `Jobs.start_sweep(..., axes, mode='manual'|'automatic', selected=...)` launches one run record and strictly serial native workers, preserving separate per-point manifests, logs and a `SWEEP_MANIFEST.json` summary. Automatic execution stops after a failed/timed-out/cancelled/stale point and keeps preceding verified points.
- `Jobs.cancel`, `Jobs.retry`, `Jobs.status` and `Jobs.archive` provide authorized cancellation, a maximum of three attempts per retry chain, scheduler-only progress checkpoints, current-vs-stale artifact evidence, and bounded ZIP artifacts. A08 owns HTTP routing for these new methods.

## Runtime constraints

A process-global mutex plus OS file lock (`.native-job.lock` under the private Store root) protects one native job per workspace, including competing processes. Windows uses `msvcrt.locking`; POSIX uses `flock`. The worker is invoked only as `sys.executable -m sqe_studio.worker` with a fixed argument list, `shell=False` and no user-specified executable. Single worker timeout: 180 seconds. Automatic sweep ceiling: 600 seconds. Poll-monitored log ceiling: 4 MiB, native file ceiling: 128 MiB, artifact ZIP ceiling: 150 MiB. POSIX process-group descendants are terminated; Windows descendant termination requires separate acceptance testing. Progress reports completed *job points*, never a fabricated solver percentage.

`status` distinguishes `is_current_revision`, `is_current_native_artifact` and `scientifically_qualified=False`. Verified bytes are not scientific convergence, PDK/LVS, calibration, or a foundry approval. Stale historical archives may be inspected but never used to validate the latest revision. A completed result is hash-verified before archive.

## Required parallel handoffs

A01 must provide trusted, versioned typed artifact references and review evidence for geometry/port/units/transformations, with exact parent artifact hashes and a verified immutable source. A02 must expose an independent QDesign recipe; A03 must emit native mesh/deck/EM artifacts and reviewed boundary/port models; A04/A05 must validate reviewed mapping before their native conversions. No graph bridge is silently inferred from output names.

A08 should connect CSRF-protected status, cancel, retry and sweep routes, and strengthen the existing raw `/result` route to check terminal successful state, source revision and artifact hashes. A09 should decide the proposed frozen-contract migration with versioned schema changes, rather than changing shared ABI here. See `reports/agents/A06/REPORT.md` for tested versions, exact foundation identity, blocked scientific acceptance and migration details.

Tests under `tests/orchestration/` use explicitly labeled synthetic **byte** fixtures to check orchestration integrity; they do not stand in for real scientific-engine acceptance.
